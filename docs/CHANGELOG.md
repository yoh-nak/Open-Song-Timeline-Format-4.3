## Musical scope inherited from the adopted release

Core 4.3 adds optional Phrasing, Vocal Freedom, Ensemble Interactions, finite Performance Plans and musical Performance Requirements to 4.2. Existing harmony, note, MIDI, lyric, vocal and provenance authorities remain unchanged.

Distributed Session 0.2 describes participants, score-byte/Plan binding, typed events, state revisions, clock anchors and commitment windows. Production Session 0.2.0 describes channels, devices, assets, automation, audio regions and sidechains independently from MIDI CC and Score notes.

## Historical material

Dated development discussions remain in the adopted source corpus solely to preserve the approved bytes and explicit precedence. They are not separate release candidates. The originating publisher approval supersedes old administrative pending/NO-GO wording. No runtime or independent interoperability certification was introduced by this release.
